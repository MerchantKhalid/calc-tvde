# TVDE Income Calculator — BDCARS Fleet

React + Vite app for TVDE drivers in Portugal.

- IVA: No IVA / 6% / 23% / custom rate
- Languages: English and Português (auto-detected, switch with EN | PT)
- Values are saved on the driver's phone (localStorage), never sent anywhere
- WhatsApp share button, add/remove expenses, installable (PWA icons included)

```
npm install
npm run dev     # development
npm run build   # production build in /dist
```
